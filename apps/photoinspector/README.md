# PhotoInspector

Geplante zweite Windows-Anwendung auf Basis von `travelcore`.

Schwerpunkte:

- Dublettensuche
- visuell ähnliche Fotos
- unscharfe, unter- und überbelichtete Bilder
- technische Qualitätsbewertung
- Fotoauswahl

Diese Anwendung ist **noch nicht implementiert**. Sie darf dieselben
GUI-freien Module verwenden:

- Bildanalyse
- Metadatenanalyse
- Hashing
- Dublettenerkennung
- Similarity
- Thumbnail-Erstellung
- Qualitätsbewertung

Keine dieser Komponenten darf eine Abhängigkeit zu PySide6 erhalten.
